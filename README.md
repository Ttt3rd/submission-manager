# submission-manager

**提出課題管理アプリ**

学校の提出課題を登録・管理し、締め切りや日々の作業予定を把握するためのWebアプリケーションです。

教科・課題名・提出期限・課題範囲を登録し、カレンダーや週間予定表を使って課題の進捗を管理できます。

- **Current Version:** α.3
- **Language:** Japanese
- **Platform:** Web Browser
- **Deployment:** GitHub Pages

## Features

### 1. 課題管理

- 教科・課題名・課題範囲・提出期限を登録
- 登録済み課題の編集・削除
- 提出状況の管理
- 課題全体の完了状態を個別に管理
- 期限に応じた課題の状態表示
- 期限超過・提出済み・作業中＆完了のタブによる分類

### 2. 教科・課題名のカスタマイズ

- 教科の追加・編集・削除
- 教科ごとの課題名の追加・編集・削除
- ドラッグ＆ドロップによる並べ替え
- 上下ボタンによる並べ替え
- 編集内容の一括保存・変更破棄

登録済みの課題には、登録時点の教科名・課題名が保持されます。そのため、マスター情報を変更しても過去の課題データには影響しません。

### 3. カレンダー

- 月単位のカレンダー表示
- 課題の提出期限をカレンダー上に表示
- 課題の状態に応じた色分け
- 課題範囲の表示

### 4. 週間予定

- 1週間単位の予定表
- 課題を予定枠に配置
- ドラッグ＆ドロップによる予定の追加
- 予定ごとの完了チェック
- 課題全体の完了チェック
- 祝日の手動設定

※予定枠のすべてにチェックを入れても、課題全体は自動的に完了になりません。課題全体の完了は専用のチェックボックスで管理します。

### 5. データ保存・バックアップ

- ブラウザのLocalStorageへの自動保存
- JSON形式でのバックアップ・復元
- Dropboxとの連携
- Dropboxへのバックアップ
- Dropboxからのデータ復元

### 6. その他

- ライトモード・ダークモード
- PC・スマートフォンに対応したレスポンシブデザイン
- 未保存の変更に対する警告

## Getting Started

### Option 1: GitHub Pages

GitHub Pagesを利用することで、ブラウザからアプリにアクセスできます。

1. このリポジトリをGitHubに配置します。
2. リポジトリの Settings を開きます。
3. Pages を選択します。
4. 公開元のブランチとフォルダを指定します。
5. 保存すると、GitHub PagesのURLからアプリを利用できます。

### Option 2: Local

`index.html` をブラウザで開くことで利用できます。

ただし、Dropbox連携を利用する場合はHTTPSまたはlocalhostでの起動が必要です。

## Dropbox Integration

Dropboxを利用すると、課題データをクラウドにバックアップできます。

### Setup

1. [Dropbox App Console](https://www.dropbox.com/developers/apps) にアクセスします。
2. Dropboxアプリを作成します。
3. OAuth 2の設定を行います。
4. Permissionsで以下を有効にします。
   - `files.content.read`
   - `files.content.write`
5. Redirect URIにアプリの公開URLを登録します。
6. 発行されたApp Keyをアプリの保存・バックアップ画面に入力します。
7. 「Dropboxに接続」を実行します。

### Backup

Dropboxへのバックアップは、アプリ内の操作から実行できます。

保存先：

`/task_manager_alpha1_backup.json`

### Restore

Dropbox上のバックアップを読み込み、現在の課題データを復元できます。

**注意：** 復元すると現在の課題データがバックアップの内容に置き換わります。

Dropboxのアクセストークンはブラウザのセッション内に保持されます。ブラウザのタブを閉じた場合などは、再接続が必要です。

## Data Storage

本アプリでは、主にブラウザのLocalStorageを使用してデータを保存します。

- 課題情報
- 教科情報
- 課題名情報
- 週間予定
- 祝日設定

LocalStorageのデータは、基本的に利用しているブラウザ・端末ごとに保存されます。

別の端末やブラウザで利用する場合は、JSONバックアップまたはDropboxを利用してください。
